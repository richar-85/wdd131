Weekend Soccer Pickup Game

The name Weekend Soccer Pickup Game was chosen because it clearly describes the purpose of the website.

It lets users immediately know that the site is about informal soccer games held on weekends and is designed for community members looking to participate in pickup-style soccer matches.

Site Purpose

The purpose of the Weekend Soccer Pickup Game website is to provide a central platform where community members can find information about weekend soccer pickup games.

The site will share game schedules, locations, and times, as well as allow players to sign up to participate in upcoming games.

This siteplan provides a platform to:

  • Post weekend soccer pickup game schedules
  • Provide game locations and times

Targeted Audience

Members of the community who enjoy soccer, including beginners and experienced players, looking for weekend social and recreational activity.

Scenarios

Scenario #1: Game Time

Question: "What time does the weekend soccer pickup game start?"

Answer: The game time will be listed on the Game Details page so players can plan their weekend schedule.

Scenario #2: Game Location

Question: "Where will the weekend soccer pickup games be played?"

Answer: The game location will be provided on the Game Details page, including the name of the field.
